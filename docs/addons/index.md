# All add-ons

Ambikly Pro ships **35 add-ons**. They are not separate plugins: they live inside Ambikly Pro, run on the same engine and database as the free core, and are switched on one at a time from <span class="screen-path">Ambikly → Add-ons</span>.

One license covers every add-on on this page. See [what Pro adds](/pro) for the difference between the free core and Pro, or [managing add-ons](/addons-manage) for how enabling and disabling behaves.
